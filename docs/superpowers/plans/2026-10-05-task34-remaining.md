## 1. 완제품 케이블의 집계 키에 길이가 들어간다

### 지금 상태 (실측)

`src/import/diagram/cables.ts` 의 집계 키는 세 가지다.

```
243행   unresolved:{lineTypeId}
321행   route-incomplete:{bulk|ready}:{productName}
338행   bulk:{productName}                              ← 길이 없음. 문제 없다
338행   ready:{productName}:{snapToStep(meters)}        ← ⛔ 길이가 키에 들어간다
```

### 무엇이 깨지나

완제품 케이블은 **길이가 키의 일부**라서, 거리를 고치면 **다른 행이 된다.**

```
거리 10m    ready:HDMI Optical Cable:10     ← 사람이 이 행의 수량을 3 으로 고쳐 둠
  ↓ 경로 입력에서 거리를 15m 로 수정
거리 15m    ready:HDMI Optical Cable:15     ← 새 행. 수량이 자동값으로 돌아감
```

**사람이 손으로 고친 값이 조용히 사라진다.** 수동 수정 보호 장치(`resetRowIds`)는
**같은 행일 때만** 작동하는데, 키가 달라져 버려서 "같은 행"으로 인식되지 않는다.

`bulk`(벌크 케이블)는 키에 길이가 없으므로 **이 문제가 없다.** 완제품만 해당한다.

### 할 것

- [ ] **먼저 시험을 쓴다.** 완제품 케이블 구간의 수량을 손으로 고친 뒤 **경로 거리를
      바꾸고**, 고친 수량이 **그대로 남아 있는지** 단언한다. 지금 코드로는 실패해야 한다.
      **실패하는 것을 확인한 뒤** 고친다.
- [ ] 완제품 행에 **길이와 무관한 식별자**를 준다. 후보는 구간(`edgeId`) + 제품이다.
      길이가 바뀌어도 같은 구간의 같은 제품이면 같은 행이어야 한다.
- [ ] ⚠ **여러 구간이 한 행으로 합쳐지는 경우를 깨뜨리지 않는다.** 지금은 같은 키를 가진
      구간들이 `push` 로 수량을 더한다(`cables.ts:202`). 식별자를 구간별로 쪼개면
      **합쳐지던 행이 갈라져** 견적서 줄 수가 늘어난다. 합산은 그대로 두고 **추적만**
      이어지게 한다.
- [ ] 저장된 작업 파일과의 호환을 깬다면 **버전을 올리고 옛 파일을 읽을 때 어떻게 할지
      정한다.** 조용히 다른 행으로 읽히면 안 된다.
- [ ] `route-incomplete:` 키에도 같은 문제가 있는지 확인한다. 이 키는 길이가 없지만
      **경로 입력이 완성되는 순간 `ready:` 로 옮겨 가므로** 그 전환에서 끊긴다.

### ⛔ 하지 말 것

품명 문자열로 "같은 제품이겠지" 판정하지 않는다. 길이만 뺀 키로 바꾸면
**같은 제품의 서로 다른 길이 두 줄이 한 줄로 합쳐진다.** 10m 세 줄과 20m 두 줄은
**다른 품목**이다(완제품은 길이별로 SKU 가 다르다).

## 2. 저장된 문서의 잡자재비가 옮겨지지 않는다

### 지금 상태 (실측)

`src/domain/quote/miscMaterials.ts` 는 **막기만 하고 옮기지는 않는다.**

```
22~25행   기존 파생 행이 이 규칙(misc-material-led-excluded-v1)이 아니면
          blocking 경고를 내고 멈춘다
32행      synchronizeMiscMaterials 는 기존 행을 retained 로 두고 건너뛴다
```

**막는 것은 맞게 돼 있다.** 자동으로 바꾸면 사용자가 모르는 사이 금액이 바뀐다.
그런데 **사용자가 확인한 뒤 옮기는 경로가 없다.** 옛 파일을 열면 **영원히 막힌다.**

### 할 것

- [ ] 옛 기준의 잡자재 행이 있는 저장 문서를 열었을 때, **무엇이 어떻게 달라지는지**
      보여주고 사용자가 **명시적으로 옮기도록** 한다. 자동으로 하지 않는다.
- [ ] 미리보기에 **옛 잡자재비 금액 → 새 잡자재비 금액**과 **제외되는 LED 캐비넷 행 목록**을
      함께 보여준다. "왜 금액이 바뀌는지" 가 보여야 한다.
- [ ] 거절하면 **지금처럼 막힌 상태를 유지**한다. 출력도 막는다.
- [ ] 기존 `basisConflict` 경로를 재사용한다. **새 충돌 검사를 만들지 않는다.**
- [ ] ⚠ **현재 LED 캐비넷 제품이 카탈로그에 0건이다**(2026-10-05 실측). 마이그레이션
      시험에 쓸 자료를 **합성으로 만든다.** 실제 LED 가 들어오기를 기다리지 않는다.
