`tools/extract_catalog.py` 는 **열 번호를 상수로** 쓴다(`READ_COLUMNS`). 하반기 파일은 열이 밀렸다.

## 3. Global Constraints

- **⛔ 열 번호를 상수로 쓰지 않는다.** 머리글로 찾고, 못 찾으면 **중단**한다.
- **⛔ 금지 머리글을 만나면 즉시 중단한다** — `제조사` · `구매처` · `영업비고` · `원가`.
  그 열만 건너뛰지 않는다. **추출 전체를 멈춘다.**
- **⛔ 추론에 실패한 값을 로그·보고서에 적지 않는다.** 잘못 읽은 열의 내용이
  매입처일 수 있다. 실패는 **열 위치와 머리글만** 보고한다.
- 원본을 저장하지 않는다. `wb.save()` 를 부르지 않는다.
- 품셈 원본 파일을 **저장소에 넣지 않는다.**
- `M/D` 와 `M/M` 을 섞지 않는다(D1 — 섞으면 약 20배 틀린다).
- `undefined` 는 미등록이고 `0` 은 0이다(설계서 §5.6).
- **LED 는 범위 밖이다.** `SKIP_SHEETS` 의 `LED전광판 계산` 이름 거르기를 유지한다.
  하반기 파일에서 이 시트가 `visible` 로 바뀌었으므로 **숨김 여부로만 거르면 들어온다.**

## Task 1 — 머리글로 열을 찾는다 (Codex 지적 3)

**Files:** `tools/extract_catalog.py`, 그 시험.

- [ ] **먼저 실패하는 시험을 쓴다.** 금지 머리글(`제조사/구매처`)이 읽기 대상 열에 오도록
      만든 합성 시트를 넣고 **중단되는지** 단언한다. 지금 코드로는 통과해 버린다.

### 머리글 읽기 규칙

- [ ] **병합 영역은 anchor 셀에서만 전개한다.** 머리글이 비었다고 **왼쪽 값을 무한히
      끌어오지 않는다**(forward fill 금지). 병합 범위 밖으로 번지면 엉뚱한 열이 이름을 얻는다.
- [ ] 공백·개행·전각을 **정규화**한 뒤 비교한다. 원본에 `품   명`, `단 가` 처럼
      공백이 섞여 있다.
- [ ] **허용 표기(alias) 목록**을 둔다. 시트마다 표기가 다를 수 있다.
- [ ] 2행(상위)과 3행(하위)의 **복합 역할**을 쓴다. `재료비`+`단 가` 가 판매단가이고
      `노무비`+`단 가` 가 노무비 단가다. **상위만으로, 하위만으로 정하지 않는다.**
- [ ] **중복·모호·결손은 전부 중단**한다. 같은 머리글이 두 열에 있으면 멈춘다.

### 좌표 계약 — 고른 열만으로는 부족하다

- [ ] 직종 열의 **`col+1` 이 노임 열**이라는 것, 노무비 단가(K)와 표준단가(V)의
      위치, **본문 시작 행**(지금 `FIRST_BODY_ROW = 4`)까지 **전부 확인 대상에 넣는다.**
      하나라도 어긋나면 중단한다.

### 품셈 코드 열(S) — 머리글이 없다

- [ ] *"`품목별 요율%` 의 왼쪽"* **만으로 정하지 않는다.** 아래 **블록 구조**를 확인한다.

```
[품셈 코드] [품목별 요율%] [할증] [표준 단가] [직종1] [노임1] [직종2] [노임2] …
    S            T          U        V         W       X        Y       Z
```

- [ ] 네 열이 **이 순서로 연속**하고, 그 다음부터 직종 쌍이 이어지는지 확인한다.
- [ ] 코드 모양을 **`7-11-1-…` 로 한정하지 않는다.** 실측에 `9-2-1-1 촬상부-브라켓-일반형`,
      `8-1-1-Slot Type 장비설치_Card설치(Module)` 가 있다. **`숫자-숫자…` 로 시작하는지**만 본다.
- [ ] **제목 행 · 품셈 없는 제품 행 · 제품 아닌 행**을 분리한다. 품셈 코드가 비었다고
      제품이 아닌 것이 아니다(실측: 판매단가 321 vs 품셈 317).

### 금지 머리글

- [ ] `제조사` · `구매처` · `영업비고` · `원가` 중 하나라도 **읽기 대상 열의 머리글**에
      있으면 **`SystemExit` 로 전체 중단**한다.
- [ ] 중단 메시지에 **그 열의 값을 적지 않는다.** 열 문자와 머리글만 적는다.

### LED

- [ ] `SKIP_SHEETS` 의 `LED전광판 계산` 을 유지한다. 하반기에서 `visible` 로 바뀌었으므로
      **이름 거르기가 실제로 동작하는지** 시험한다.

### 노무비 역산 — **전 행을 분류한다** (지적 4)

- [ ] 모든 시트에서 역산한다.
      `(공수 × 노임) 합계 × 품목별 요율 × (1 + 할증) = 노무비 단가`
- [ ] **모든 행을 네 갈래로 분류하고 수를 보고한다.** 합이 전체와 맞아야 한다.

```
통과      역산이 맞았다
불일치    역산이 틀렸다                ← 1건이라도 있으면 교체 차단
미검증    공수·요율·노무비 중 하나가 없어 계산할 수 없었다   ← 이유별로 나눈다
비대상    제목 행 등 제품이 아니다
```

- [ ] ⛔ **`미검증` 을 통과로 세지 않는다.** 1판 시범의 119건이 여기 있었는데
      이유를 나누지 않았다.
- [ ] ⛔ **"불일치가 일정 수를 넘으면 중단" 이라는 임계치를 두지 않는다**(1판의 오류).
      **1건이라도 있으면 교체를 막는다.** 넘기려면 **사유를 적은 승인 목록**을 둔다.
- [ ] `Decimal` 로 계산한다. 부동소수를 쓰지 않는다. **`INT` 를 어디서 적용하는지**
      원본·도메인·Excel 세 자리를 구분해 주석에 적는다.
- [ ] **수식 캐시를 믿을 수 있는지 확인한다.** 캐시가 없거나(`data_only` 가 `None`),
      외부 참조이거나, 사람이 손으로 덮어쓴 값이면 **`미검증` 으로 분류**한다. 통과가 아니다.

## Task 4 — SKU 대응 계약 (Codex 지적 1 — 통째로 다시 씀)

**Files:** `src/app/workspace.ts`, `src/data/catalog/*`, 그 시험.

### 지금 무엇이 깨지나 (코드로 확인함)

`src/app/workspace.ts:232`

```ts
const product = catalog.products.find((p) => p.sku === r.sku);
if (product !== undefined) return withResolvedProduct(r, product, catalog.prices.get(r.sku));
```

**SKU 만으로 찾아 그 제품으로 치환한다.** `catalog-item-removed` 경고는 **SKU 가 아예
없을 때만** 난다. SKU 는 `시트코드-원본행번호` 이고 하반기 파일은 행이 늘었다
(영상 407→429, 케이블 281→326, 오디오 343→389).

→ **같은 번호가 다른 제품을 가리키면, 재계산이 조용히 엉뚱한 제품으로 바꾼다.**
  문서 열기를 막는 것만으로는 부족하다. **재계산 경로가 따로 있다.**

### 할 것

- [ ] **먼저 실패하는 시험을 쓴다.** 같은 SKU 가 다른 제품을 가리키는 두 카탈로그를 만들고,
      재계산이 **조용히 치환하지 않는지** 단언한다. 지금 코드로는 치환해 버린다.
- [ ] **대응 계약을 만든다.** `(저장 당시 카탈로그 지문, 그때의 SKU)` → **검증된 새 identity**.
      대응표에 없으면 **치환하지 않는다.**
- [ ] 대응을 **품명·규격만으로 판정하지 않는다.** 같은 모델이라도 설명·단위·구성이
      다르면 다른 제품이다(실측: `V-160HD` 가 `아이패드 제외`/`포함` 두 줄,
      `Bridge UHD M_OTR` 이 `EA`/`SET` 두 줄).
- [ ] 대응이 **모호하거나 사라졌으면 사람이 다시 고르게** 한다.
      ⛔ **원본 SKU 로 되돌아가는 fallback 을 만들지 않는다.**
- [ ] 교체 전후의 **SKU → (품명·규격·설명·단위) 대응표**를 만들고 **뜻이 바뀐 SKU 를
      전부 나열**한다.

### 시험 범위 — 열기만이 아니다

- [ ] 저장 문서 **열기**
- [ ] 재계산 **미리보기 · 적용 · 취소 · 실행취소**
- [ ] 출력 **0·1·2 단계**
