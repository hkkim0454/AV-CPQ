## 같은 제품의 판매단가

제품 신원 다섯 값이 일치한 옛 제품 1,262건이 자동 대응되었습니다. 그중 **새 SKU 하나에 옛 SKU 여러 개가 연결된 5건**과 양쪽 중 단가가 미등록된 7건을 제외하고 1,250건의 가격을 직접 비교했습니다. 미등록은 0원과 구분했습니다.

공통 SKU는 1,212개입니다. 현재 코드의 **신원 다섯 값**(품명·규격·단위·설명·묶음)으로 비교하면 같은 번호가 다른 제품을 가리키는 건수는 1,029건입니다. 전달받은 1,024건은 묶음을 제외한 네 값으로 비교하면 재현됩니다. 이 보고서와 교체 안전 장치는 현재 코드의 다섯 값 기준을 사용합니다.

자동 대응되지 않은 옛 제품은 206건입니다. 그중 173건은 후보가 있어 **사람이 고르는 중**이고, 33건은 같은 품명의 후보도 없습니다. 새 제품 중 자동 대응의 대상이 되지 않은 것은 328건입니다. 따라서 206건을 모두 삭제 제품, 328건을 모두 신규 제품이라고 단정할 수 없습니다. 이 범위의 단가도 인상·인하 통계에 넣지 않았습니다. 판매단가가 있는 옛 제품 189건과 새 제품 326건이 이 자동 대응 밖에 있습니다.

## 품셈 연결과 제품 묶음

자동으로 같은 제품이라고 확인된 1,262건에서는 1,149건이 양쪽 모두 품셈에 연결되어 있고 113건은 양쪽 모두 연결이 없습니다. 이 범위에서 **연결이 사라지거나 새로 생긴 건수는 각각 0건**입니다. 자동 대응 밖에는 현행 연결 182건과 준비 자료 연결 292건이 있습니다. 이 숫자는 제품 신원이 확정되지 않았으므로 삭제·신규 연결 건수로 읽을 수 없습니다.

옛 묶음 이름으로는 13개 묶음의 품셈 연결이 준비 자료에서 0건입니다. 묶음 이름 자체가 바뀐 경우에도 이렇게 잡히므로 제품과 품셈이 모두 없어졌다는 뜻은 아닙니다. 특히 `4K 매트릭스 스위처_RTCOM_XDM`은 옛 연결 18건 중 16건에 후보가 있고 2건은 같은 품명의 후보가 없습니다. `Televic` 7건, `JBL 스피커_라인어레이` 5건, `EVER` 7건, `KVM_제어` 7건, `Encodulator` 4건은 모두 후보가 있으나 자동 확정되지 않았습니다. 기존 `XDM-12`와 `XDM-HI100`도 하반기에는 묶음 이름이 `_DANTE`로 바뀌어 사람 확인 대상입니다.

또한 케이블에서 옛 `CBL-0006/0007/0008`이 새 `CBL-0006` 하나에, 옛 `CBL-0095/0096`이 새 `CBL-0098` 하나에 자동 연결됩니다. 신원 문구는 일치하지만 서로 다른 옛 단가가 하나의 새 단가로 합쳐질 수 있습니다. **가격 비교에서는 이 다섯 건을 제외**했으며, 실제 SKU 대응을 확정하기 전에 각각 확인해야 합니다.

## 이 단계의 판단과 남은 작업

실행해서 확인한 사실은 제품·단가·품셈 총량이 늘었고, 자동으로 동일성이 확인된 제품에서는 10배 이상 단가 변동이나 새 0원 가격이 없으며, 위의 두 제품 견적은 최종 금액이 4,770,000원 올랐다는 것입니다. 묶음 이름이 사라진 이유와 173건의 미결정 대응, 33건의 후보 없는 옛 제품, 케이블의 여러 대 일 대응은 아직 사람 확인이 필요합니다. **5-B의 다섯 파일 교체는 진행하지 않았습니다.**

재실행 명령은 `npx vite-node tools/probe_pumsem_compare_cli.ts`입니다. 도구는 두 디렉터리의 JSON을 읽고 표준 출력에 집계만 표시합니다.

검증은 `npm run verify`에서 자동 시험 1,244건, 추출기 시험 25건, 내보내기 감사를 모두 통과했습니다. 별도로 `npm run test:extract`에서 25건, `npx playwright test`에서 브라우저 시험 103건을 통과했습니다. 이번 단계에서는 원본 엑셀을 다시 추출하거나 준비 자료를 배포 폴더로 옮기지 않았습니다.
