# 견적 작업 편의 1차 개선

> 실행: superpowers:executing-plans. 사용자 승인: 개선 방향 제시 뒤 “진행해 줘”.

## 목표와 범위

미저장 견적의 이탈·교체를 보호하고, 직접 선택에서 모델명과 후보 정보를 찾으며, 기존 견적에 추가할 시스템을 고른다. 이번 범위는 제안한 1차 개선이다. 계산 정책·노무 확인·원가 저장 정책·자료·배포는 변경하지 않는다.

## 작업 순서

- [x] A: 저장 상태와 교체/이탈 보호. workspace에서 마지막 저장 문서와 현재 문서를 비교한다. 새 문서는 미저장, 작업 파일 재열기는 저장 상태, 편집은 미저장, 저장 후 undo/redo는 내용으로 판정한다. 저장 실패는 미저장 상태를 유지한다. 파일 읽기 실패나 교체 취소는 기존 문서를 보존한다. 새 구성도/작업 파일 적용 직전에 현재 상태를 확인한다. beforeunload는 미저장 상태에서만 등록한다. 브라우저의 다운로드 완료/실제 디스크 기록 여부는 웹에서 알 수 없으므로 표시 문구에 다운로드 요청 기준임을 알린다.
- [x] B: 직접 선택 검색을 model/quoteSpec/quoteName/SKU/description으로 확장하고 정확한 모델명 일치를 우선한다. 자동 연결은 하지 않는다. 기존 후보 표시를 공유 컴포넌트로 분리해 모델·규격·설명·단위·판매단가(미등록/0 구분)를 보여준다. 결과 20개 제한은 전체 건수와 더 보기로 해소한다.
- [x] C: 기존 견적의 시스템 목록을 picker에 전달한다. 다중 시스템에서는 명시 선택 전 추가를 막는다. 선택된 systemId만 도메인 addItem에 넘긴다. 단일 시스템은 기본 선택한다. 추가 후 선택 화면은 유지하며 추가 결과와 닫기 버튼을 제공한다.

## 검증

각 작업은 기능 부재를 재현하는 Playwright 시험을 먼저 실행한다. A: 새 견적→저장→편집→undo/redo→교체 취소/수락, 이탈 취소 시 보존, 실패 파일 보존. B: 모델 전용 검색, 동일 모델의 설명·가격·단위 구분, 0/미등록 구분, 명시 SKU 선택. C: 구성도로 두 시스템 생성→두 번째 시스템 선택→추가→저장 파일 systemId 대사→undo. 합성 자료만 사용한다. 전체 단위/E2E, 타입검사, 원가 격리 감사와 빌드를 실행한다. 화면은 데스크톱과 좁은 폭에서 변경한 영역을 확인한다.

## 경계

자동 복구/영구 저장은 이번에 추가하지 않는다. 공개 push·배포는 하지 않는다. 현재 작업 폴더를 쓰는 기존 사용자 방식을 유지하고 로컬 작업 브랜치로 구분한다. 작업 기록과 합성 산출물은 .local/codex-review에 둔다.

## 실행 결과 (2026-10-09)

- Codex가 수정 전 브라우저 시험 4건의 실패를 직접 확인했다. 저장 상태·이탈 경고·모델 검색·시스템 명시 선택의 부재를 재현했다.
- 입력 중인 견적 필드도 보호하도록 보완했다. 추가 시험에서 저장한 문서의 입력 중 고객명이 경고 없이 사라지는 것을 먼저 재현했다. QuoteDrafts는 미반영 여부만 메모리에 보관하며 원가 파일을 읽지 않는다.
- 작업 파일 읽기를 지연시킨 뒤 구성도를 선택·저장하는 시험에서 이전 작업 파일이 새 구성도를 덮는 문제를 재현했다. 두 파일 입구가 선택 순서를 공유하도록 수정했다.
- 신규 브라우저 시험 6건을 포함해 전체 113/113, 단위·통합 1255/1255, `tsc -b --force`, `audit:exports`(100파일, 화면18), `npm run build`가 통과했다. 빌드의 500KB 청크 안내는 남아 있다.
- 기존 견적 교체 시험 2건에는 새 미저장 확인창을 승인하는 동작을 추가했다. 자동 연결·노무 확인·계산 정책은 변경하지 않았다.
- 별도 검토자는 코드를 읽고 검토했다. 다운로드 요청 기준임을 명시하라는 문구 지적을 반영했고, 파일 선택 순서 후속 수정도 읽기 전용으로 확인했다. 이 검토자의 시험 재실행으로 보고하지 않는다.
- 데스크톱 1440px와 좁은 화면 390px에서 변경된 품목 선택 영역을 캡처·육안 확인했다. 기존 견적표 전체의 작은 화면 재설계는 2차 범위다.
- 공개 push·배포는 실행하지 않았다. 브라우저 종료·비정상 종료 후 자동 복구를 제공하는 기능은 아니며, 사용자가 내려받은 작업 파일을 보관해야 한다.
